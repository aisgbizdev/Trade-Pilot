description: Intentional XAU/USD timeframe focus alongside an all-instrument overview

Keep XAU/USD as the default focus for timeframe performance, while the overview can cover all instruments. Users should be able to choose another instrument; do not replace this default with an aggregate timeframe view just because the overview says “all.”

**Why:** The user explicitly clarified that this default is intentional. The concern was ambiguous reset wording, not the underlying statistics or selection flow.

**How to apply:** In future History & Performance UX changes, preserve the default and make the scope of controls clear with precise labels rather than changing aggregation behavior.
