Additional verified instruments should receive the same non-Adaptive analysis services, detail structure, menu placement, and content quality as the four main products. Adaptive is the only intentional product-specific exclusion. Their print/save-PDF action belongs **inside** Detail Analisis, not as a separate button above an old strip of navigation chips. Include an analysis-time chart in the detail and PDF when historical candles are available; if not, say so rather than substituting a live chart.

**Why:** The user explicitly corrected implementations that either left the additional-instrument chip menu in place or matched the container but offered less detail and no chart. They then clarified that all instruments outside the four main products should get the same services except Adaptive. They want parity in both layout and substance, with PDF accessed from the matched detail surface.

**How to apply:** When changing analysis presentation, compare the main and additional-instrument journeys side by side. Reuse saved-analysis detail UI and ordering wherever possible, while never implying Adaptive calculations are available for additional instruments.
